# Glossaire de relecture (français soutenu, québécois, termes techniques anglais conservés)

Règles de relecture (passe intégrale `f2-batch` / `f2-apply`) :
- Ne renvoyer que les phrases modifiées. Conserver le balisage (**gras**, `code`, listes `- `, titres `##`) et les placeholders.
- Aucun tiret cadratin. Vouvoiement partout. Pas de familiarité (« ça », « un peu », « plein de », « tout le monde » -> « tous »).
- Corriger : fautes d’orthographe/accord, calques, tournures lourdes, ponctuation (« : » en double dans les titres), incohérences de terminologie, contradictions.
- Ne jamais toucher aux identifiants, noms de tables/champs, commandes, URL, noms d’éléments d’interface en anglais.

Terminologie canonique :
- Noms de produits Microsoft : toujours en anglais (Defender for Office 365, Defender for Endpoint, Defender for Identity, Defender for Cloud, Defender for Cloud Apps, Defender XDR, Microsoft Entra, Entra ID, Microsoft Sentinel, Microsoft Purview, Intune, Azure Logic Apps). Jamais « Defender pour ... ».
- Fonctions : « Advanced Hunting » (plus « chasse avancée »), « Threat Explorer » (plus « explorateur de menaces »), « live response », « Safe Links », « Safe Attachments », « ZAP » (suppression automatique en heure zéro à la première mention), « Endpoint security » pour le nœud Intune.
- « portail Defender » ; « centre d’administration Intune » ; « accès conditionnel » (minuscules) ; « protection contre la falsification » ; « catalogue de paramètres » ; « base de référence de sécurité » ; « politique de conformité ».
- « politique » (jamais « stratégie » pour policy ; « stratégie » reste pour strategy ; « stratégie de groupe » = GPO, on écrit GPO).
- « point de terminaison » (jamais « terminal/terminaux » pour endpoint) ; « poste » (poste de travail) ; « appareil » (device).
- « locataire » (jamais « tenant », sauf nom de fonction : Tenant Allow/Block List).
- « infonuagique »/« nuage » (jamais « cloud » seul dans la prose, sauf noms de produits et de services) .
- « courriel », « hameçonnage », « pourriel », « maliciel » (jamais « malware », « phishing », « email » dans la prose), « rançongiciel ».
- « billet » (ticket ITSM) ; « ticket Kerberos » reste.
- « laboratoire » (jamais « lab »).
- « identifiants » (credentials) ; « jeton » (token) ; « consigne » (prompt système) ; « invite » (prompt utilisateur, une fois défini : « invite (prompt) »).
- « journal » (log) ; « tableau de bord » ; « liste de contrôle » (checklist) ; « retour arrière » (rollback) ; « moindre privilège » ; « capteur » (sensor) ; « plugiciel » (plug-in).
- « prend en charge » (pas « supporte ») ; « établir » (pas « bâtir ») ; « satisfait/remplit » une condition -> « rempli ».
