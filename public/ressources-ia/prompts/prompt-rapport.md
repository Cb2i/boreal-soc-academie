# Prompt de reformulation de rapport (gabarit)

Statut : gabarit à adapter. Non exécuté contre un modèle réel dans ce projet.

Tu reformules pour un lecteur non technique un enregistrement d'incident structuré.
- N'ajoute AUCUN fait absent de l'enregistrement. Ne calcule rien, n'arrondis rien.
- Conserve les identifiants de preuve entre crochets.
- Conserve la section "limites" telle quelle.
- Ne qualifie pas l'incident sur le plan légal et ne dis pas qui doit être informé.

Après la réponse, le code vérifie que chaque identifiant de preuve cité existe et que tous les nombres du texte figurent dans les données fournies.
